# ScoutAlert design previews

Ink + citron is the selected direction as of 29 September 2026. Apply its cool white, ink, and restrained citron palette, Manrope typography, and crisp controls to the onboarding interface. The opening illustration and live scout brief use light surfaces; ink remains in text and compact controls.

The [original theme comparison](scoutalert-themes.html) includes Ink + citron, Graphite + cobalt, and Midnight + copper. The latter two remain available as reference explorations. Ink + citron was selected after comparing additional designs.

The later Google-inspired comparison remains exploration rather than the selected application theme.

## Parked exploration

The newer design preview is saved for a later review at the user's request. It is not selected as the product design and has not been applied to the application.

- [Standalone preview](parked/scoutalert-fresh-direction.html): open in a browser to review the saved exploration.
- [Editable fragment](parked/scoutalert-fresh-direction.fragment.html): the original preview source, preserved unchanged.

The preview uses illustrative opportunities and local interactions. It does not create accounts, run scouts, or send alerts.
